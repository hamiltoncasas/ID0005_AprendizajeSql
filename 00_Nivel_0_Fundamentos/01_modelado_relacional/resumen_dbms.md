# Resumen: DBMS

Un DBMS (Database Management System) es un sistema de software que permite crear, organizar, administrar y consultar bases de datos.
Facilita el almacenamiento y la recuperación de información de manera ordenada y eficiente.
También permite modificar y eliminar datos cuando sea necesario.
Un DBMS ayuda a controlar el acceso de los usuarios y mantener la seguridad de la información.
Además, puede mantener la integridad de los datos y evitar errores o duplicaciones innecesarias.
Entre sus funciones están crear tablas, realizar consultas y administrar las relaciones entre los datos.
Tres ejemplos de DBMS son MySQL, PostgreSQL y Microsoft SQL Server.

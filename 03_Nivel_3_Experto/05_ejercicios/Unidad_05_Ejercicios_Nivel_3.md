# Módulo 05 — Ejercicios integradores del Nivel 3

> El nivel experto se demuestra resolviendo problemas de nivel experto.

## 🎯 Objetivo

Integrar optimización, modelado, administración y SQL analítico en ejercicios reales.

## ✅ Ejercicios

- [ ] `ejercicio_01.sql` — Optimiza una consulta con JOIN de 3 tablas y filtros
      (guarda plan antes/después en comentarios).
- [ ] `ejercicio_02.sql` — Reporte ejecutivo: ventas por trimestre, con subtotales
      por categoría usando `ROLLUP`, y variación vs. año anterior.
- [ ] `ejercicio_03.sql` — Diseña un esquema 3FN para una tabla dada (en comentarios)
      y crea el script `CREATE TABLE` final con índices y FK.
- [ ] `ejercicio_04.sql` — Crea un rol de solo lectura, una vista de negocio
      y comprueba que el rol puede usar la vista pero no ver columnas sensibles.
- [ ] `ejercicio_05.md` — Caso de estudio: "la consulta que tarda 5 minutos".
      Describe diagnóstico, plan de acción y resultado final (puedes simular datos).
- [ ] `ejercicio_06.sql` — Reto: ranking global de rendimiento. Crea 2 versiones de
      una misma consulta analítica, mide tiempos y plan, y elige la mejor justificando.

## 📦 Entregables

- `ejercicio_01.sql` … `ejercicio_04.sql`, `ejercicio_06.sql`
- `ejercicio_05.md`

## 🏁 Autoevaluación

- [ ] Puedo leer un plan de ejecución y señalar el operador más costoso.
- [ ] Puedo diseñar un esquema normalizado con índices y roles.
- [ ] Puedo armar un reporte analítico con subtotales y comparativas anuales.

> Cuando completes esto, marca el nivel en `../Guia_Nivel_3_Experto.md` y empieza el
> **Proyecto Final**. 🏆

## 📂 ¿Qué debe colocar la persona en esta carpeta?

Todo el **trabajo realizado**, en cualquier formato:

- 🖼️ **Imágenes** (`.png`, `.jpg`): diagramas, capturas de pantalla de resultados.
- 📄 **Word** (`.docx`): resúmenes, informes o explicaciones.
- 📊 **Excel** (`.xlsx`): tablas de datos, cálculos o comparativas.
- 🗄️ **Base de datos** (`.db`, `.sqlite`): la base de datos trabajada.
- 💾 **Consultas y scripts** (`.sql`): ejercicios resueltos y scripts creados.

> Regla de nombres: un archivo por actividad, con nombre descriptivo
> (ej: `diagrama_er_final.png`, `practica_joins.sql`, `resumen_actividad.docx`).
